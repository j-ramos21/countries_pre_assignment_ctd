# countries_pre_assignment_ctd
## Description
This program is the pre-assignment for Code the Dream developed to fetch data from the public API https://countries.dev/countries, process the data, and gives users information about countries.
## Structure
* functions_pa.py - Includes the 3 functions used by the main file.
* main.py - Executes the program using the main function.
## Requirements
The only requirement is to have Python 3.12.11
## How to Use Program
1. Download this repository.
2. Run main.py.
3. Input a region (Africa, Americas, Antarctic, Antarctic Ocean, Asia, Europe, Oceania, and Polar).
4. Input a country in chosen region.
