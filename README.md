# countries_pre_assignment_ctd
## Description
This program is the pre-assignment for Code the Dream developed to fetch data from the public API https://countries.dev/countries, process the requested data, and finally display information about countries to the user. The program takes inputs from the user, what region and what country from that region, and then gives that country's capital, currencies, and languages.
## Structure
* functions_pa.py - Includes the 4 functions used by the main file.
* main.py - Executes the program using the main function.
## How to Run Program
1. Download this repository.
2. Run main.py.
3. Input a region (Africa, Americas, Antarctic, Antarctic Ocean, Asia, Europe, Oceania, and Polar).
4. Input a country in chosen region.
